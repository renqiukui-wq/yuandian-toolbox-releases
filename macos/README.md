# 元点剪辑批量工具箱 · macOS 0.1.1

这是独立的原生 Mac 首版，支持 **macOS 13+、Apple Silicon 与 Intel**。使用 SwiftUI、AVFoundation 和系统编码器；无需安装 Python、Node、FFmpeg 或 Windows 程序。源码采用仓库 MIT 许可证。

## 0.1.1 使用体验修复

- 草稿列表先显示，预览逐项载入；缺图自动重试，手动刷新强制重读，支持停止扫描及关闭自动刷新。
- 缺封面的草稿会继续查找后续可用素材，不再只查看前八个引用；图片缩略解码减少内存占用。
- 素材按块复制、显示进度，可及时取消；取消和失败只清理本次临时副本。支持再次打包已有素材副本。
- 视频队列可移除单项和已完成项；再次开始仅处理未完成项，失败原因可展开查看。视频提示不再被草稿刷新覆盖。
- 记住视频输出目录，启动时检查 Mac 更新；按版本号选择最新版本，显示下载量/进度，可取消和重新下载。校验通过后才写入用户选择的文件。
- 保持 Apple 芯片和 Intel 通用；仍不包含剪映复杂时间线直接导出或 Mac 自动安装。

## 下载与安装

在本仓库名称以 **macos-v** 开头的 Release 中下载 **YuandianToolbox-macOS-universal.dmg**，打开后把应用拖入 Applications。也提供 ZIP。不要下载 Windows EXE。

当前安装包只有本地 ad-hoc 签名，尚未使用 Apple Developer ID 签名和公证。首次运行可能被 Gatekeeper 阻止；确认从本项目下载后，按 macOS“系统设置 → 隐私与安全性”中对此应用的提示允许打开。不要关闭系统整体安全保护。正式面向大众无提示分发需要维护者的 Apple 开发者证书及公证流程。

## 首版可用功能

- 草稿库多选、搜索、封面、素材预览和放大。
- 每 15 秒及应用重新激活时检查已保存的草稿和封面内容；相同修改时间但图片内容改变也会刷新。
- 优先显示剪映生成的封面；缺封面时尝试素材画面，并明确标识。旧封面早于草稿修改时给出提示。未保存编辑不能读取，不能把素材画面视为完整时间线渲染。
- 为可解析 JSON 草稿复制一个含素材的新副本；逐个校验 SHA-256、重写副本路径、生成素材清单，不改原草稿。加密草稿、缺失素材、符号链接或处理时发生变化会报错，不虚报成功。
- 批量处理已导出视频：原尺寸、自动 720P、1280×720、720×1280。自动模式适配每条视频方向与比例；固定模式等比缩放补黑边。
- 默认第一帧或随机画面替换第一帧作为封面；保留时长与音频。不同播放器对缩略图的选择可能不同。本版不写入 MP4 attached_pic 流。
- 输出目录只保留最终 MP4；不生成原版备份，不修改输入视频。遇同名文件拒绝覆盖。
- 深色、浅色、跟随系统；取消任务；任务期间阻止意外退出。
- 独立 Mac 更新检查、应用内下载与 SHA-256 校验、网站下载入口。下载后解压替换应用；首版未实现 Mac 自动安装。

## 与 Windows 版的区别

**本版不是 Windows 版全部功能的等价移植。** 原 Windows 软件后端及 DLL 没有可移植源码，Mac 版不提供剪映复杂草稿/多时间线的直接批量渲染、不解密加密草稿，也没有原 Windows 全套混剪功能。请先在 Mac 剪映导出视频，再用本工具批量处理视频。无法解析的草稿仍可以读取已保存的封面。

素材副本包含本机路径，跨电脑移动后需要在剪映重新定位素材；本版不承诺直接跨机打开。素材副本是否被当前剪映版本接受仍需用户用自己的草稿验证。

## 自行构建

在安装 Xcode 命令行工具的 Mac 上执行：

    cd macos
    bash build.sh test
    bash build.sh

输出位于 macos/outputs/。脚本编译 arm64、x86_64 后合并为 Universal 2 应用，并检查签名和架构。GitHub Actions 会在 Apple 芯片和 Intel runner 上运行真实视频测试，然后发布独立 Mac 预发布版本；不会改变 Windows latest 更新通道。

验证还覆盖复制/视频取消与临时文件清理、已打包草稿再次打包、较后素材预览、更新版本排序与下载哈希校验。

验证覆盖：草稿发现、同时间戳封面变化、素材副本路径与校验、原文件保留、同名冲突、缺素材、加密草稿、四种输出尺寸、音频和时长、随机第一帧、后续帧、旋转视频以及无临时输出残留。CI 不替代真实剪映草稿兼容性和桌面交互测试。
