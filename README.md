# 元点剪辑批量工具箱

Windows 单文件版，支持多草稿、多时间线批量处理。

## 下载

[打开最新版本下载页](https://github.com/renqiukui-wq/yuandian-toolbox-releases/releases/latest)

在 **Assets** 中下载 **YuandianToolbox.exe**，双击运行即可。可以将它改名为“元点剪辑批量工具箱.exe”。原生导出需要本机剪映环境。

## 软件内更新

1. 打开工具箱，进入“检查更新”。
2. 查看版本号和更新说明，点击“下载新版”。
3. 等待下载完成及文件校验通过，点击“打开下载位置”。
4. 完成当前任务并退出旧版，用下载的新 EXE 替换旧文件。

从 v1.0.1 开始接入此发布渠道。此前尚未配置更新渠道的版本，请先手动下载一次。

## 主要功能

- 多草稿、多时间线批量导出，按时间线名称命名。
- 保持原尺寸、自动 720P、固定横屏与固定竖屏。
- 自动 720P 根据每个输出视频的画面比例等比缩放。
- 草稿素材整理与备份。
- 深色、浅色主题。

GitHub 下载速度取决于网络连接。本仓库用于发布程序与更新说明。
