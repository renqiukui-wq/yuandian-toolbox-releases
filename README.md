# 元点剪辑批量工具箱

多草稿、多时间线批量处理工具的开源定制工程。Windows 应用版本：**v1.0.8**；另提供独立的 **macOS 0.1.1 预览版**。

**开源范围：** 本仓库公开我们编写的界面扩展、预览服务、素材整理、更新器、单文件启动器及补丁/构建脚本，采用 MIT 许可证。原始 Go/Wails 主程序的完整源码不在本仓库中，完整应用仍依赖使用者自行提供的兼容原始程序及第三方文件。详见 [开源范围与外部依赖](THIRD_PARTY.md)。

## 选择你的系统

| 系统 | 下载 | 范围 |
| --- | --- | --- |
| Windows x64 | [Windows 最新版](https://github.com/renqiukui-wq/yuandian-toolbox-releases/releases/latest) · YuandianToolbox.exe | 原有批量导出与定制功能 |
| macOS 13+，Apple 芯片或 Intel | [Mac 0.1.1 通用版](https://github.com/renqiukui-wq/yuandian-toolbox-releases/releases/tag/macos-v0.1.1) · Universal DMG / ZIP | 草稿预览、可解析草稿素材打包、已导出视频的尺寸与首帧处理 |

Mac 应用完整源码位于 [macos](macos)，使用原生 SwiftUI / AVFoundation，不依赖 Windows 原程序。**Mac 首版尚不支持直接渲染剪映复杂草稿、多时间线或原 Windows 全套混剪功能**；请先在 Mac 剪映导出视频。安装包未使用 Apple Developer ID 公证，首次启动可能需要在系统“隐私与安全性”中允许打开。详见 [Mac 安装、功能范围与构建说明](macos/README.md)。两套更新通道独立，Mac 预发布不会替换 Windows latest。

Mac 0.1.1 改善了逐项预览、缺图重试、大素材复制取消、视频队列重试和更新下载进度；下载支持取消，并在保存前校验文件。Apple 芯片与 Intel 均运行视频、素材、网络下载测试和深浅色窗口验证。

## 获取源码

点击仓库 **Code → Download ZIP**，或使用 Git：

```powershell
git clone https://github.com/renqiukui-wq/yuandian-toolbox-releases.git
cd yuandian-toolbox-releases
```

当前源码位于 main 分支。早期 v1.0.1–v1.0.4 的发布标签是在公开源码之前创建的；要获取这次公开的代码，请下载 main，或克隆后使用 main 分支。

## 构建与验证

环境要求：Windows x64、Python 3.9+、Node.js 18+、Zig 0.13.0、.NET Framework 4.x 的 64 位 C# 编译器（csc.exe）。构建脚本只使用 Python 标准库；Acorn 8.15.0 已连同其许可证放入仓库。

不需要原始 EXE 即可检查公开的辅助程序和测试：

```powershell
python build.py --check
```

此命令编译公开的 C# 辅助程序，验证草稿封面缓存更新/删除/恢复、导出参数和更新安装等待逻辑；它不会启动剪映，也不会访问个人草稿。

完整打包需要自行提供：

- 原始安装目录，包含“小映批量助手.exe”和 Resources 下的 bravo.exe、f2.exe、ffmpeg.exe、MediaInfo.exe、qcore_ext.dll、uptool.exe。
- 草稿读写 DLL 从本仓库 draft_codec.c 编译，使用 Windows CNG，不再需要另行提供旧桥接 DLL。
- 支持的原始 EXE SHA-256：`016012b4a179f428cc90e2b2520c761606bb773c572803abd0fb6f64485785ee`。脚本会拒绝其他二进制版本，避免错误补丁。

```powershell
python build.py --original-dir "D:\BuildInputs\original" --zig "D:\Tools\zig\zig.exe"
```

Node 不在 PATH 时添加 `--node "C:\path\to\node.exe"`。构建中间文件在 `.build`，最终单文件程序在 `outputs\元点剪辑批量工具箱.exe`。输入文件只读；脚本不会替换正在使用的已安装程序。

构建包含前端语法/补丁检查、原始文件哈希及指定修改区验证、打包文件完整性检查。Windows 编译器可能写入不同的构建时间，因此不承诺不同机器生成的 EXE 逐字节一致。

Fork 后请修改 `release_config.json` 中的版本、GitHub 发布仓库和附件名称，避免你的派生版本从本项目更新通道下载更新。

## 软件内自动更新（v1.0.3 起）

1. 打开工具箱，启动后自动检查新版；也可以进入“检查更新”手动检查。
2. 查看更新说明，点击“下载并更新”。
3. 下载完成并校验通过后，等待当前导出或素材处理结束。
4. 程序自动退出旧版、替换原 EXE 并重新启动，无需手动覆盖文件。

下载慢时，可点击“去网站下载”打开最新版本页。打开网页不会取消软件内下载；需要切换时请先取消当前下载。网站下载是备用方式。

**首次从 v1.0.1 / v1.0.2 升级：** 旧版可以检查并下载 v1.0.3，但旧客户端尚无自动安装代码，这一次仍需退出旧版并替换 EXE。升级后，后续软件内更新可自动替换并重启。

## 草稿预览（v1.0.4 起）

所有草稿选择列表显示缩略图，点击“放大”可查看封面。优先读取剪映保存的草稿封面；缺少封面时尝试从素材生成识别图，并标注“素材画面”。素材画面不代表完整时间线效果。

可见列表每 15 秒检查封面，切回工具箱或刷新列表时也会检查。封面内容改变后自动更新，不需要重启。请先在剪映保存修改；尚未保存的编辑、剪映尚未生成的新封面无法显示。素材缺失或无法读取时显示提示，可点击重试。预览只读取草稿，不改写草稿内容，不在导出目录生成图片。

## 直接使用所选草稿导出（Windows v1.0.8）

- 单草稿和多时间线导出直接使用所选草稿目录及已有素材引用，移除导出前自动复制素材的步骤。
- 导出页移除“导出前复制全部素材到草稿”“立即复制所选草稿素材”和素材备份说明；旧版保存的复制开关不再生效。
- 导出准备不再执行素材复制器的草稿占用检查，不再因为这个复制步骤要求关闭草稿。
- 尺寸处理、随机封面仍在视频导出后执行；处理视频的临时目录不会替换所选草稿目录。
- 验证覆盖旧复制设置为 true、旧 busy 状态、中文自定义草稿目录、单草稿与 13 条时间线、原尺寸与自动 720P / 随机封面组合。接口回归检查不代表完整剪映渲染已经实测。

## 草稿读写兼容修复（Windows v1.0.7）

- 修复安装剪映 11.7 后旧读写桥接返回错误 -3，导致素材整理及后续导出无法启动的问题。
- 使用独立的 Windows CNG 草稿编解码组件，同时替换素材服务与原导出内核内置组件；使用新的缓存文件名，防止沿用旧 DLL。
- 保留文件认证校验、写入前变化检测及失败回滚；遇到不支持或损坏的文件，报告具体文件，不继续写入。
- 已在故障草稿副本上验证 15 个加密文档、13 条时间线及 21 个外部素材复制，并用独立实现交叉检查读写结果。原草稿未修改。尚未验证完整剪映视频渲染流程，这些结果不等于所有剪映版本和草稿格式均兼容。

## 导出启动修复（Windows v1.0.6）

- 启动准备期间只接受一次导出请求，避免重复点击干扰正在初始化的任务。
- 新任务被后台接受前，不再把上一次任务的完成状态当作本次结果。
- 启动前检查后台是否已有导出；失败后释放准备状态并保留原始错误。
- 错误面板显示失败阶段，可复制详情；诊断写入本机日志，写日志失败不阻塞重试，不上传个人草稿。
- 已验证 13 条时间线和随机封面的参数传递、重复请求拦截、旧进度隔离及失败恢复；真实剪映原生导出仍需在使用者环境验证。

## 导出与封面

- 多草稿、多时间线批量导出，文件名沿用时间线名称。
- 支持保持原尺寸、自动 720P、1080P、2K（1440P）和 4K（2160P）；逐条跟随视频横竖方向，保持比例。旧固定横竖设置自动迁移为自动 720P。
- 常见横屏分别输出 1280×720、1920×1080、2560×1440、3840×2160；竖屏交换宽高，其他比例按短边缩放。
- 尺寸和像素比例已匹配、无旋转且无需删静音/随机封面时，直接交付文件，跳过二次编码。放大低清素材只改变尺寸，不会恢复原本不存在的细节。
- 尺寸处理成功后，只在所选目录中保留最终视频，不生成原尺寸备份。
- 多时间线封面支持默认首帧、随机画面帧及自选图片。随机帧写入视频首帧并内嵌封面，保持时长和音频，不另存图片。
- 使用尺寸转换、导出后删静音或随机封面时，请选择自定义保存路径；遇到已有同名视频会提示，避免覆盖。
- 支持草稿素材整理、深色与浅色主题。

## 删气口改进（Windows v1.0.5）

- 单草稿：先在剪映保存，再选草稿，自动读取并检测；使用“保守”或“均衡”，点击“生成无气口草稿并排齐”。原草稿保留，生成旁边的无气口副本。可重新读取检测；过期检测结果不再串到新草稿。
- 批量草稿：可多选已保存草稿的主时间线，逐项生成无气口草稿或导出视频；逐项显示成功/失败，可重试未完成项，或在当前项结束后停止排队。
- 多时间线：在导出设置勾选“导出后删除静音并自动排齐”。处理最终导出视频的第一条音轨，默认 -40 dB、0.5 秒，切口两侧各保留 80 毫秒；音视频同步裁切后拼接，尺寸转换和随机封面合并为一次编码。
- 修正强度 100 对应 0 dB、容易把整段语音判断为静音的问题；强度范围改为 -60 至 -20 dB，异常旧设置恢复到 -40 dB。检测将删除 80% 以上内容时停止该项，提示调整规则；视频批次继续处理其余文件。
- 无音轨或无须删除的导出视频直接进入尺寸判断；失败的视频保留临时源文件方便恢复。成功目录只留最终视频，不生成原尺寸备份。
- 删气口期间，软件内更新等待处理完成后再替换重启。

**当前限制：** 尚不能直接读取并修改剪映正在打开、尚未保存的当前时间线。快捷生成和批量草稿使用原程序现有的草稿处理接口；复杂草稿的特效、字幕、变速和多轨兼容性仍取决于该接口，需在副本中核对结果。本版未用你的实际草稿执行破坏性测试。静音检测不是语音识别，连续背景音乐可能使停顿无法被判为静音。

验证包含 C# 编译、原二进制完整性、前端语法/交互、批量失败重试、自动更新等待，以及使用实际 FFmpeg 的尺寸跳过、横竖屏转换、音轨/时长、全静音保护和失败隔离测试。真实媒体测试可在完成构建后运行：

```powershell
python test_export_media.py --resources "D:\BuildInputs\Resources"
```

GitHub 下载速度取决于网络连接。本仓库用于发布程序与更新说明。
